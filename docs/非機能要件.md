# Campus Secretary AI: 非機能要件

## 開発目的

- 大学2年生の授業「プログラミング演習」の課題として開発。
- 作成物は自由で、成果物のプレゼンに対する学生同士の相互評価をもとに課題としての完成度を評価する。
- そのため、技術的な高さよりも「相互評価で高評価を得られるか」「どんな人でも分かりやすくすごいと感じるもの」を重視して開発する
