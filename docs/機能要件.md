# Campus Secretary AI: 機能要件

## 概要

大学生向けAI秘書アプリ。
Discordをメインインターフェースとし、AIキャラクターがユーザーとの会話を通して課題管理を行う。

単なるチャットボットではなく、

- ユーザーの課題
- 会話履歴
- 長期記憶

を保持し、継続的な人格を持つAIとして振る舞う。

ユーザー向けの説明:

```
Taskieは、課題管理と日常会話を通して学生生活をサポートするAI秘書です。
課題の登録、リマインド、相談相手まで担当し、あなたの行動を覚えながら継続的に成長します。
```

## コンセプト

「AIに命令する」のではなく、**「AIと一緒に生活する」** ことを目指す。

通知は通知として送らない。AIが自発的に話しかけてくる。

例:

- 「提出期限まであと1日ですが、本当に終わっていますか？」

## MVP

### 機能1: AIチャット

Discord上で会話できる。用途は以下の通り。

- 雑談
- 相談
- 課題登録
- 課題解説

### 機能2: 課題管理

ユーザーの課題を管理する。

自然言語

例: レポート金曜まで → 課題生成

または

例:
課題名: 情報工学レポート
締切: 2025/06/15

### 機能3: 課題解説

ユーザーがテキストおよびPDF・画像で課題を送信できる。

AIは

- 要約
- 解き方説明
- ヒント

を返す。

※回答丸投げよりも「解説」に寄せる

### 機能4: Webダッシュボード

管理画面。表示内容は以下の通り。

- 今日の状況: 未完了課題数、締切間近課題数
- 課題一覧: 課題名、締切、状態
- AIコメント
- AIによる日記: AIの目線で書かれた日記。ユーザーの行動や会話をもとにAIが1日の振り返りを書くイメージ。

## AIによる状態管理

AIは会話から情報を抽出する。

例:

- 「来週火曜までにレポートやらないとな」 -> 課題登録候補生成
- 「応用情報受けようと思う」 -> 長期記憶候補生成
- 「レポート終わった」 -> タスク完了候補生成

AIは裏側で構造化データを生成する。

## 長期記憶

AIは重要情報を保持する。

例:

- 学年
- 学科
- 興味分野
- 資格目標
- 研究室候補

後日の会話でこれらの情報を活用する。

例: 「応用情報を受けると言っていましたが、勉強は進んでいますか？」

## 通知システム

通知という概念を表に出さない。全て会話として送る。

- 提出期限3日前「そろそろレポートに手を付けた方が良いと思います。」
- 提出期限1日前「明日締切ですが、本当に大丈夫ですか？」
- 期限超過「終わったと思っていましたが、終わっていなかったんですね。」

## ランダム会話

AIが自発的に話しかける。人格の演出と、ユーザーとの関係構築が目的。

例:

- 「今日は講義どうでしたか？」
- 「最近忙しそうですね。」
- 「応用情報の勉強は進んでいますか？」

送信タイミングは 1日2〜5回程度、ランダムなタイミングで送る。

- 課題状況
- 会話履歴
- 長期記憶

などを参照するが、完全な雑談を混ぜることで、ゆらぎのある自然な会話を目指す。

## 人格設計

人格はここで定義するが、今後変更の可能性を考え、実装では変更しやすい設計にする。

### 方針

- 毒舌だが好意的
  - 軽い煽り: OK
  - ツッコミ: OK
  - 世話焼き: OK
  - 攻撃的: NG
  - 不快: NG

- 課題追加: 「また増えたんですか。」
- 課題完了: 「珍しく仕事が早いですね。」
- 期限超過: 「予想通りです。」
